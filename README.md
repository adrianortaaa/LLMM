# Lenguajes de Marcas (LLMM) 📚

Este repositorio contiene todos los ejercicios, prácticas y proyectos realizados durante el módulo de **Lenguajes de Marcas y Sistemas de Gestión de Información**.

El objetivo es organizar y documentar el aprendizaje sobre la estructuración de información, diseño web y lenguajes de transferencia de datos.

## 🛠️ Tecnologías utilizadas

* **HTML5:** Estructuración de contenido web.
* **CSS3:** Diseño, maquetación y estilos (Flexbox, Grid).
* **XML:** Almacenamiento y estructuración de datos.
* **JSON:** Intercambio de datos ligero.
* **Markdown:** Documentación del proyecto.

## 📂 Estructura del Repositorio

El contenido está dividido por unidades temáticas o bloques de aprendizaje:

* **T1 - Introducción a los Lenguajes de Marcas:** Conceptos básicos y primeros pasos.
* **T2 - HTML & CSS:** Creación de páginas web estáticas y diseño responsivo.
* **T3 - XML:** Definición de documentos, DTD y XML Schema.
* **T4 - Transformación de datos:** (Si tienes archivos XSLT o similares).
* **T5 - Sistemas de Gestión de Información:** Almacenamiento y recuperación de datos.

## 🚀 Cómo visualizar los ejercicios

1.  Clona el repositorio:
    ```bash
    git clone [https://github.com/adrianortaaa/LLMM.git](https://github.com/adrianortaaa/LLMM.git)
    ```
2.  Navega a la carpeta deseada.
3.  Si es un archivo `.html`, simplemente ábrelo en tu navegador favorito.
4.  Para archivos `.xml` o `.json`, se recomienda usar un editor de código como **VS Code**.
